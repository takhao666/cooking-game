Sizzle & Serve — Tiny Bistro Rush: a one-chef kitchen chaos game. Orders land on the board, and you run the whole kitchen yourself: grab ingredients from the pantry, chop them on the board, cook patties, pasta and broth on the stove, plate each dish on the counter and ring the bell at the serving window before the ticket's patience runs out. Serve fast for tips, chain serves for a combo bonus, and survive the lunch rush across days that keep getting busier — new recipes unlock as you go.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD / arrow keys or by clicking, use a station with E or by clicking it, and hold E at the chopping board to chop. No build step, no network requests — plain static files under `game/`.
